# 洛谷同步

洛谷适配器读取个人公开主页和练习清单，使用数字 UID。此功能不要求提供平台密码；公开数据受限时可在本机设置页更新 Cookie。Cookie 沿用 AES-GCM 加密存储，不返回到前端。

本次联调 UID 1591246 的公开数据：115 道通过题，练习清单中有 121 个不同题号，48 天站点活动。主页同时报告尝试题数 120，与练习清单不一致，因此两个数字分别保留，不强行改写。

## 数据口径

- platform_problem_inventory 保存通过和尝试题号、官方难度及本次观察时间。观察时间不是解题日期。
- v_problem_progress 将题目清单与原 record 表按用户和题目去重，供题目总量、平台统计、题型和难度统计使用。
- 清单不包含逐题日期、提交编号或提交次数，不写入 synced_submission，也不创建带有猜测日期的 record。
- platform_daily_activity 单独保存主页 dailyCounts 第一项的站点活动值，原始第二项不当作提交量或 AC 数。
- 热力图新增“站点活动（洛谷）”指标。选择洛谷时自动选择该指标；活动值不与提交数、AC 数混算。
- 原有月度统计和近七天逐次提交统计只使用有日期的原记录或真实同步明细，因此不从洛谷清单推算日期。
- platform_snapshot 保存每次同步的清单数量及主页报告数量，便于识别源站返回差异。原有示例记录继续保留，汇总可能比公开清单大。
- 练习页返回的难度按洛谷官方档位展示，不换算成 CF rating。洛谷没有当前能力参考值所需的 CF/AT 数字尺度，所以不混入该指标。

请求失败、隐私限制或验证页面会报错，保留旧数据。清单和活动写入使用事务，重复同步按题号及账号日期更新，不重复累加；不会因为暂时缺失的旧活动而清空历史。
