# 提交记录与分页

导航“最近记录”改为“提交记录”。旧列表为最近 8 道题的汇总，现在使用真实提交明细 synced_submission；同题多次提交保留多行，不将洛谷清单和手工汇总伪造成提交。

GET /api/submissions?page=1&pageSize=25 提供当前用户的数据。页容量限定 10/25/50/100，页码为正整数；超出末页自动返回最后一页。计数和当前页在同一个只读一致性事务中查询，按 submitted_at DESC、submission_id DESC 稳定排序。009 迁移增加 verdict 及 (user_id,submitted_at DESC,submission_id DESC) 索引。

客户端每次仅请求和显示当前页，提供前后页、有限页码按钮、跳页及重试；切页取消旧请求，并校验响应序号，避免快速点击时旧结果覆盖新结果。进入提交页不请求完整 dashboard。正常情况下每页最多渲染 100 行。当前个人数据量下 LIMIT/OFFSET 足够；极大数据量或很深页码可改游标分页，COUNT 和深 OFFSET 仍有额外成本。

CF 和 AT 保存平台真实判定；QOJ 不再固定筛选 100 分，读取可识别的已判定 AC、WA、超时、超内存、编译错误等记录。未评测、不可识别状态不凭空归类。历史只有 passed=0 的数据展示“非 AC · 历史判定未保存”，再次同步到同一提交时补充 verdict。判定从 WA 改为 TLE，即使 passed 仍为零也更新。牛客和力扣目前主要为 AC 数据，洛谷仅清单/活动，不能据此表示完整提交历史。

题目链接使用数据库保存的 http(s) 原题地址，在新标签页打开并设置 noopener noreferrer。没有原题地址时显示纯文本。

验证：36 项单元测试、隔离数据库中同步幂等/重判/回滚测试、分页接口与数据库前两页逐条比对、非法参数/末页处理及 EXPLAIN 索引验证通过。浏览器验证翻页、10 条容量、跳页和 WA/TLE 展示，生产构建通过。
