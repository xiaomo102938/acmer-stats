# 统一难度与题型能力

实现版本：acmer-cf-v1，2026-11-03。

## 数据来源与空白原因

洛谷练习清单只包含题号、标题和难度档位。先前未获取算法标签，旧能力视图也只接受 CF 和 AT 的原始数值，因此洛谷题数存在而能力参考为空。本次新增题目元数据采集，通过官方站点 `_lfe/tags` 标签字典解释题目页的标签 ID，只导入 type=2 的算法标签，并沿其明确的父子关系补充上位题型。年份、来源和赛事标签不作为算法标签。DP 等别名归并到既有规范标签；细分算法保留。

首次按每题至少四秒串行采集，成功后缓存三十天。每题独立事务写入，失败不清空旧数据，重试跳过缓存内的成功题目。`metadata_checked_at` 只在成功读取元数据后更新。此模块不生成提交、AC 时间或逐题日期。

## 调研结论与采用方法

可参考的项目有 Silver_Fox 的 [Rating Converter](https://silverfoxxxy.github.io/rating-converter) 及其 [原作者说明](https://codeforces.com/blog/entry/93069)、[Luogu Rating Predictor](https://github.com/EndeavourChiu/Luogu-Rating-Predictor)、[cf-difficulty-predictor](https://github.com/sreeharsha-mondemu/cf-difficulty-predictor)。它们分别解决选手 rating 关联、旧七档难度粗估、基于题面训练难度模型。没有将其当作精确且统一的官方题目评分服务。

本项目采用轻量、确定性的估分规则，原始难度及来源不被覆盖。公式集中在 `src/backend/ability.js`，仪表盘和题单接口共用。不会在页面渲染期间调用第三方服务或训练模型。

| 平台与条件 | CF 尺度数值 | 性质 |
| --- | --- | --- |
| CF 有官方题目 rating | 直接使用 | 官方题目分 |
| 洛谷能精确匹配已导入的 CF 同源题 | 使用对应 CF 官方分 | 同源官方依据 |
| AT 有 AtCoder Problems 数值 | round100(clamp(3900 × (d+940) / 5155, 800, 3900)) | 低置信实验外推 |
| 洛谷当前八档难度 | 800、1000、1400、1800、2000、2200、2700、3200 | 低置信档位估分 |
| 未评定、来源缺失、QOJ/牛客/力扣缺少依据 | 不计分 | 不从空数据猜分 |

AT 公式的线性关系取自选手 rating 换算器；把题目难度代入是本项目的实验外推，尚无同题配对校准。限制在 800–3900 后按百位取整，是避免伪精度的产品约定，不是统计误差范围。AtCoder Problems 的低分显示修正仍由原有采集模块完成，不重复修正。

洛谷已采用[当前八档体系](https://help.luogu.com.cn/manual/luogu/problem/difficulty)：入门、普及-、普及、普及+/提高-、提高、提高+/省选-、省选/NOI-、NOI/NOI+/CTS。旧社区映射只有七档，本项目插入“提高=2000”，其余数值参考旧映射。这是人工规则，没有宣称经过训练或具有已验证准确率。

不采用“通过人数 / 注册总用户数”直接换算：注册用户不是活跃题目暴露人群，题龄、赛事选手范围、练习偏好、重复提交都会引入偏差。后续可使用同场参赛者及其赛前 rating 拟合解题概率，并用跨平台同源题校准；当前尚未实现这一研究型模型。

## 能力计算

1. 从 `v_problem_progress` 获取当前用户去重后的做题状态，关联题型与原始评分。
2. 按选择的平台筛选；默认“全部平台”。可识别的 CF/洛谷 CF 镜像、AT/洛谷 AT 镜像按规范来源键合并。仅识别明确来源 ID，不按相似标题合并。
3. 同一题型下仅保留已通过且有有效评分的题目，按 CF 尺度降序取最多 25 题，求算术平均，保留一位小数。
4. 不足 25 题标注“样本不足”；没有评分依据时显示空值。满样本优先排序，样本量充足并不会消除换算偏差。
5. 点击分数可查看实际入选题单、原始平台、原始难度、评分方法、置信性质及日期是否可用。展示入选估分题数，避免将整榜误认为 CF 官方成绩。

旧 `v_tag_ability` 保留为按平台原始尺度的历史 SQL 视图；网站统一尺度榜由 `abilityProfiles` 提供，不再混用该视图。总量视图按平台内题目去重，而能力榜额外合并可识别的跨平台同源题，两者口径明确区分。

## 验证

新增固定样本单元测试验证八档映射、AT 换算、缺失排除、最高 25 题、重复提交、简单题新增不降分、同源题去重、标签父子关系及不制造时间。接口测试逐行核验所有非空能力榜与返回题单的均值、范围、估分题数和规范题目键唯一性。测试期间应等待元数据刷新结束，避免两次请求之间数据变化导致快照比较失效。

## 综合能力参考

使用全部已通过题目，不要求存在标签。按同一估分与同源题去重规则，取最高 15%（向上取整），至少取 120 题。每个题目无论具有多少标签都只计一次；有效题数不足时按零分补齐目标题数，未评级题不进入候选样本。仪表盘只返回汇总，GET /api/ability/overall 按需返回入选题单，页面每页展示 25 道。新增测试覆盖无标签题、同源镜像、低分新增、失败排除、最低样本数和空样本。
