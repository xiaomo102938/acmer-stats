# 题型客制化、拓扑与专职能力

设置页新增“题型与技能图谱”，包含专职题型、多标签归并和拓扑编辑。配置归属当前本机个人用户，保存在 MySQL user_skill_settings 的 JSON 字段中；不改写平台原始标签、problem_tag 或提交记录。

## 操作

1. 专职题型可多选；勾选包含分支后，只沿主前驱的实线关系纳入后代，不沿虚线扩展。选中图谱以外的现有标签也有效。
2. 标签归并选择来源和目标标准题型，加入草稿后统一显示与统计；可撤销。系统现有中英文标准化继续生效。新同步题目的标签在下一次分析时自动经过个人别名映射。
3. 拓扑编辑先选择已有题型添加为独立根节点，再选择节点、更改显示名、主前驱及副前驱。已有六个方向 37 节点作为默认配置；其余标签可手动加入，避免一次出现大量节点。只允许使用现有标签与默认知识节点，不任意创建无数据含义的标签。
4. 预览只演示草稿关系，题数为 0；保存后分析页使用真实题数。恢复默认只修改草稿，保存才生效。取消编辑重新读取已保存配置，离开页面的未保存草稿不会生效。

## 约束

根节点没有任何前驱。非根节点恰有一个主前驱，允许多个副前驱。禁止自身前驱、重复前驱、主副前驱重复、悬空引用和任意实虚混合环。前端即时提示并禁用保存，后端独立再验证。检测使用 DFS 对两种边合并检查。

移除仍被下级或关联引用的节点会被阻止，先修正引用再移除。归并的来源若有连线，也先要求改为孤立根并处理其下级，避免静默丢失关系。归并必须直接指向标准题型，禁止别名链、循环及归入自身；不物理删除标签，可撤销。撤销别名时来源作为独立根恢复，不猜测旧关系。

显示名称 1～100 字符，图谱最多 400 节点。保存使用数据库事务、用户行锁和 revision 乐观并发检测，旧窗口不能覆盖其他窗口的修改。没有额外的上游网络请求，API 沿用本机写入来源校验。

## 统计与图谱

题型表格与图谱对别名关联取并集，按 canonicalProblem 去重，同题多标签及可识别镜像不重复计算。节点不累加子节点题数。入选题单接口同步采用标准题型键，保证点击分数后的题单与均值一致。

综合能力默认按专职范围筛选，再选最高 150 道已通过、有评分依据的唯一题目求均值；不足 150 道标注样本不足。无专职时引导去设置，不默认给出全题综合分。下拉框仍可选择全部题目参考，包含无题型但有评分的题。缺少题单或标签的主页汇总不会虚构到专职能力中。

自定义图谱支持任意层级实线树与跨分支虚线；定位深层节点会展开其全部主前驱路径。节点大小、文字缩放、配色和原有稳定视口保持，展开仅触发短时有界排布，稳定后冻结。
