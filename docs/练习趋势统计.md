# 练习趋势统计

范围：按月选择年月（默认当月）、按年选择年份（默认当年）、生涯（所选平台首条已同步提交至今天）。页面初始为当年、按月、全部平台、首次 AC 题数。

粒度：按月支持日、周；按年支持日、周、月、季；生涯支持日、周、月、季、年、3 年。切换范围恢复该范围的默认粒度。周从周一开始，季度使用自然季度；3 年从生涯首条已同步提交所在年起分组。分组边缘只计入选择范围内的日期，页面汇总和悬停提示标出实际起止时间；当前月、年截至服务器当天。

指标：提交次数、AC 提交次数、首次 AC 题数。首次 AC 先按当前用户与题目在完整已同步历史中求 MIN(submitted_at)，再筛选显示范围；不会将某月重复 AC 当作新题。多账号同题合并，平台间不同 problem_id 不自动视为同一道题。缺失历史不能还原，洛谷清单和手工题目汇总不生成虚构提交。

GET /api/trends 参数 mode=month/year/life、grain=day/week/month/quarter/year/threeYear、month=YYYY-MM、year=YYYY、platform=all/平台名。服务端验证参数组合、月份年份及平台；使用参数化查询和只读一致性事务。MySQL 先按天聚合提交及首次 AC，后端补零并按所选粒度汇总，仅返回分组结果。无新增数据表。

前端指标切换直接使用已返回的三个计数，不重复请求。范围/粒度/平台改变取消旧请求，响应序号防止过时数据覆盖；图表实例复用、关闭动画，ResizeObserver 响应宽度，离开页面时释放资源。日数据超过 90 个点启用 ECharts 缩放条和内部缩放，默认最后 90 天。仍发送完整日聚合序列，未下载原始提交列表。

验证：41 项单元测试通过；API 测试对照真实数据库逐条记录，核对范围、平台和各分组的三种指标，包括完整历史的首次 AC。覆盖周跨月、闰年、当前年截断、季度、3 年分组、空分组和非法参数。浏览器已验证指定月份、按周、生涯粒度选项及日缩放条，生产构建通过。
