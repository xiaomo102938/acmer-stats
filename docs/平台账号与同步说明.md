# 平台账号与数据同步

账号入口位于侧栏“设置”页面中的“平台账号与同步”。支持添加、编辑会话设置、手动同步和解绑；同一平台可保存多个用户名。解绑保留已同步记录。

## 数据范围

| 平台 | 获取方式 | 当前范围 |
| --- | --- | --- |
| Codeforces | 官方 user.status API | 每次最多最近 5000 条公开提交，达到上限时明确提示 |
| AtCoder | AtCoder Problems 第三方 API | 每次最多 5000 条，保存进度；后续同步回看前一天并继续，按提交 ID 去重 |
| QOJ | 提交列表，需要登录 Cookie | 仅可见 AC 提交，最多 20 页；登录失效或网站防护会明确报错 |
| 力扣中国 | 公开最近 AC GraphQL 接口 | 最近 AC 列表，不保证完整历史；需填写主页 /u/ 后的用户标识 |
| 牛客 | 数字 UID 对应的个人练习列表 | 可见 AC 提交，最多 20 页；未包含全部比赛及失败提交 |
| 洛谷 | 公开主页与练习清单 | 通过/尝试题号、官方难度及站点活动，无逐次提交及逐题日期 |

需要完整历史的用途，不能把“最近 AC”或部分 AC 列表当作全部记录，也不能把缺失的失败提交推算为零。当前看板通过率只针对数据库中已有的题目样本。同步不会清空旧记录。

不同平台原生难度不直接换算成四档。CF 原生 rating 和 AtCoder Problems 社区估计值保存在 native_difficulty，并由 difficulty_source 标记来源；记录和分布图优先展示原生分数，缺失时显示“暂无公开难度”。AtCoder 社区估计值不是官方比赛题目得分。AtCoder Problems 可能存在收录延迟。由于使用增量回看，超过回看窗口的旧提交重新评测不一定能自动更新。Codeforces 每次重读最近窗口，可以更新窗口内的判定。

## 会话与本机配置

Codeforces 和 AtCoder 的公开数据无需平台密码。QOJ Cookie 从本人已登录的 QOJ 请求中复制完整 Cookie 请求头值，在本机网页的账号编辑表单中保存；不要提交到 Git 或粘贴到文档中。Cookie 以 AES-256-GCM 加密存入原 platform_account.login_pwd 字段。ACCOUNT_SECRET_KEY 为 32 字节随机密钥的 64 位十六进制表示，仅保存在忽略的 .env 中。请妥善保留密钥；更换或丢失密钥后需重新填写 Cookie。

服务仅监听 127.0.0.1，不作为有公开访客的部署版本。当前使用本机单用户模式，没有部署级的用户登录系统。写接口要求专用请求头并检查 Origin；如将来需要公开部署，先补身份认证和访问权限。

牛客 UID 位于个人主页 URL 的数字部分；用户名或昵称不能代替 UID。QOJ 两个账号分别保存 Cookie；如果站点当前只允许同一登录用户读取自己的历史，请对应填写各自会话。程序不处理验证码或绕过平台防护。

## 数据一致性

新增 synced_submission 表，按用户、平台、平台提交 ID 唯一去重。原有 record 保留手工部分，远程记录按实际获取的提交聚合，并与原手工部分合并，不调用旧的“每次累加”录入存储过程。写入提交、题目标签、汇总记录和成功状态在同一事务中完成；任何一步失败则全部回滚。

同一平台的两个账号不能同时写入，使用 MySQL 命名锁串行处理。进程重启会将未完成任务标记为中断，用户可以重试。单条记录仍受旧字段 999 次提交上限约束，超过时显示值截断到 999，逐条提交明细仍保留于 synced_submission。

当前录入功能指平台账号录入；手工刷题记录编辑页面尚未实现。未来新增手工刷题记录写接口时，应同时维护 manual_submit_count、manual_passed、manual_solve_date，不能仅修改聚合值。

## 初始化与迁移

已有本机数据库已应用 003_account_sync.sql。其他已有数据库按 001、002、003 顺序迁移，003 只执行一次。不要对现有数据库执行会 DROP DATABASE 的全量初始化脚本。全量 sql/acmer_stats.sql 已包含新结构，仅用于新建数据库。

原有 14 道初始化题目仍保留，真实同步记录与这些原有题目共同参与统计。

## 测试

- npm test：解析、状态处理、Cookie 加密和篡改检测。
- node --env-file=.env tests/sync-database.mjs：使用随机名称的独立测试数据库验证重复同步、原手工记录保留、标签关联、重新判题和事务回滚，最后删除该测试库。需要创建测试数据库权限。
- node --env-file=.env tests/accounts-http.mjs：临时账号的添加、编辑 Cookie、返回值脱敏、重复绑定、来源校验及解绑。
- npm run build：前端生产构建。
