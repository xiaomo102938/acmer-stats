# 题型技能图谱初版

入口：详细分析 → 题型能力参考 → 技能图谱。与分页表格共享平台筛选和既有能力统计，不新增数据库表或重复下载完整提交。

手工整理六个方向、37 个节点：动态规划、图论、数据结构、数学、字符串、搜索。实线表示基础与分支，虚线表示跨方向关联；树形 DP 关联动态规划、树与 DFS。这是初版知识导航，不是严格学习前置或自动推断的课程顺序。未整理的标签继续出现在表格，页面展示未覆盖数量。

节点直径按 24+2.4×sqrt(去重通过题数) 缩放，上限 72；不累加子节点的题数。数据取自当前平台能力统计的 passed_count，沿用同源题去重。缺少节点数据时显示零，不代表用户没有学习过。一个题目可有多个标签，因此不能将所有节点题数相加作为总通过数。

颜色：无有效评分为灰色；不足 25 道有效评分通过题为暂定色；满样本按 CF 尺度参考值 <1800、1800–2399、≥2400 分色。估分误差仍然存在，非实际个人 CF rating。

SVG 固定分支布局，无力导向模拟、无持续动画。默认展开 DP，支持分支展开/收起、全部展开、缩放滑块、滚动、重置、下拉定位、键盘选择节点。点击节点查看通过题数、能力参考和样本；可打开既有最高 25 题入选题单。点击相关知识可展开并定位到对应节点。

验证：知识图无循环、无悬空或重复边、节点唯一，树形 DP 多基础关系正确；题数不叠加、缩放单调且封顶、无评分/不足样本状态分开。真实页面 DP 显示 107 题，树形 DP 显示 3 题，联动入选题单有 3 条记录。生产构建通过。
