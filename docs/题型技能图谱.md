# 题型技能图谱初版

入口：详细分析 → 题型能力参考 → 技能图谱。与分页表格共享平台筛选和既有能力统计，不新增数据库表或重复下载完整提交。

手工整理六个方向、37 个节点：动态规划、图论、数据结构、数学、字符串、搜索。实线表示基础与分支，虚线表示跨方向关联；树形 DP 关联动态规划、树与 DFS。这是初版知识导航，不是严格学习前置或自动推断的课程顺序。未整理的标签继续出现在表格，页面展示未覆盖数量。

节点直径按 24+2.4×sqrt(去重通过题数) 缩放，上限 72；不累加子节点的题数。数据取自当前平台能力统计的 passed_count，沿用同源题去重。缺少节点数据时显示零，不代表用户没有学习过。一个题目可有多个标签，因此不能将所有节点题数相加作为总通过数。

颜色：无有效评分为灰色；不足 25 道有效评分通过题为暂定色；满样本按 CF 尺度参考值 <1800、1800–2399、≥2400 分色。估分误差仍然存在，非实际个人 CF rating。

SVG 使用有界物理布局，计算完成后静态显示，无持续动画。默认展开 DP，支持分支展开/收起、全部展开、缩放滑块、滚动、重置、下拉定位、键盘选择节点。点击节点查看通过题数、能力参考和样本；可打开既有最高 25 题入选题单。点击相关知识可展开并定位到对应节点。

验证：知识图无循环、无悬空或重复边、节点唯一，树形 DP 多基础关系正确；题数不叠加、缩放单调且封顶、无评分/不足样本状态分开。真实页面 DP 显示 107 题，树形 DP 显示 3 题，联动入选题单有 3 条记录。生产构建通过。


## 自动排布与冻结

布局包含反平方距离斥力、近距离碰撞间隔、边的弹簧力、速度阻尼、弱中心力及逐步冷却；关联边的弹簧较弱。布局区域设边界，防止不连通分支漂散。节点仍不可拖拽，点击只查看或展开分支。

每批计算预算约 4ms，批次之间用一次性定时器让出主线程；不逐帧绘制运动，仅发布最终坐标。连续 20 轮最大位移低于 0.08 布局单位时冻结，最多 700 轮后也停止。结束后不再安排计算定时器；离开页面或新布局开始会取消旧任务。展开/收起改变节点或边时才重新排布，并从已有坐标开始；平台筛选只改统计和样式，缩放/选择节点不重启模拟。

测试覆盖稳定停止后坐标不变、有界且有限的坐标、节点间距、不连通分支、确定性结果、迭代上限、重合起点分离和展开保留位置。当前测试默认 12 节点在 230 轮冻结；全部 37 节点冷启动在 325 轮冻结（热启动轮数不同）。本机纯计算约数毫秒至数十毫秒，浏览器总耗时还包含调度与绘制，不保证所有设备相同。

## 展开收起时的页面稳定性

排布期间保留上一份已完成的节点、边和坐标，新布局完成后一次替换，不再用 display:none 隐藏 SVG。绘图区固定 560px 高，状态提示固定单行，节点详情保留最小高度；图谱区域关闭滚动锚定，避免局部位置变化牵动页面。实际鼠标收起/展开 DP 时，页面 scrollY 均为 2170、文档高度均为 3325、绘图区高度均为 560px；构建通过。
