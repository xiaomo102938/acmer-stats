# 个人刷题数据分析网站 acmer-stats

《互联网应用服务开发与数据库实践》期末项目 · 汪林辰 · 241240027

面向 ACM/OI 选手的本地个人练习看板。它汇总多平台题目和提交，用可追溯的题型能力参考生成练习题单。应用由 Vue 3、ECharts、Vite、Express 和 MySQL 8.0 实现，默认监听 `127.0.0.1:3000`。

## 本地启动

准备 Node.js 22.12 或更新版本、npm 和正在运行的 MySQL 8.0。以下命令在仓库根目录执行。

1. 执行 `npm ci` 安装锁定版本的依赖。
2. **首次建库**时，在 MySQL 客户端中执行 `source sql/acmer_stats.sql`。脚本会删除并重建同名 `acmer_stats` 库，并载入课程示例数据。**已有库**先备份，只按编号执行 [sql/migrations](sql/migrations/) 中尚未应用的迁移，当前最新为 019。
3. 将 `.env.example` 复制为 `.env`，按本机环境填写 `DB_HOST`、`DB_PORT`、`DB_USER`、`DB_PASSWORD` 和 `DB_NAME`。需要保存平台 Cookie 时，用下方命令生成 64 位十六进制密钥，填入 `ACCOUNT_SECRET_KEY`。保留原密钥才能解密以前保存的 Cookie。
4. 执行 `npm run build`，再执行 `npm start`。访问 [本机网站](http://127.0.0.1:3000/)。关闭网站时，在运行服务的终端按 `Ctrl+C`。

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

Windows 也可双击 [start-site.cmd](start-site.cmd)，脚本会查找 Node.js、构建并启动网站。在开发模式下保持后端运行，另开终端执行 `npm run dev`，Vite 会代理 API。数据库密码、Cookie 和密钥保存在本机，`.env` 已列入 Git 忽略规则。

## 页面与演示顺序

| 页面 | 验收操作 |
| --- | --- |
| 数据简览 | 查看累计题数、AC 题数和近 7 天活动。热力图默认显示截至今天的近 365 天，可按年份查看。点击日期会跳到个人提交，并为个人和 QOJ 两张卡片填入同一天。 |
| 个人刷题分析 | 切换专职和综合能力参考，查看入选题单、能力变化趋势、练习统计、难度分布和知识图谱。在题型表搜索标签，打开对应提交或推荐练习。 |
| 团队赛分析 | 查看 QOJ 场次趋势、模拟奖牌和 AC 题难度分布。选择场次复盘赛内过题、罚时和赛后补题。点击 QOJ 过题分布的档位，跳到对应档位的 AC 提交。 |
| 提交记录 | 个人提交和 QOJ 提交分别分页。按题名、题号或备注搜索，并按判定、标签、题型和日期筛选。个人提交按 CF 尺度筛选，QOJ 提交按奖牌档位筛选。每题可保存 30 字符备注。 |
| 设置 | 查看账号同步状态，测试增量同步和重新扫描历史。可切换主题、字号和卡片间距，管理专职题型、标签归并、知识图谱及题目评测类型。 |


能力参考按 CF 尺度计算。取最高 15% 的有效评分通过题（向上取整）。专职综合至少 125 道、全部题目综合至少 250 道、单题型至少 20 道，缺额按零分计入，可识别的同源题只计一次。AtCoder 与洛谷使用估分，牛客暂按题库原分减 300 估算，QOJ 单独按奖牌档位统计。**能力变化趋势**从启用时开始积累快照，服务启动、成功同步或保存题型设置后，数值、样本或计分范围变化时写入。切换计分范围或评分版本会断开折线。

## 同步来源与范围

| 平台 | 配置与数据范围 |
| --- | --- |
| Codeforces | 填写用户名。公开提交可含 AC 和非 AC，题目带官方难度及标签。 |
| AtCoder | 填写用户名。提交与难度来自 AtCoder Problems。 |
| QOJ | 填写用户名和登录 Cookie。导入可访问的已判定提交，代理设置见下方说明。 |
| 牛客 | 填写数字 UID 或个人主页链接。优先使用公开 AC 数据，平台要求登录时可配置 Cookie。 |
| 洛谷 | 填写数字 UID。导入可见练习清单、站点活动及题型元数据。清单与逐次提交采用独立口径。 |
| 力扣 | 填写力扣中国个人主页 `/u/` 后的标识。公开近期 AC 与主页累计数据分别统计。 |

同步由用户在设置页触发。平台账号卡片右上角的「同步全部」按账号依次执行，显示当前进度和成功、失败、跳过数量。题单和提交统计以实际取得的数据为准。新库中的课程示例可以展示页面，真实提交趋势和「待攻克」筛选依赖已同步的提交记录。应用面向单机个人使用。

### QOJ 奖牌题数据

可在本机 `.env` 中将 `QOJ_MEDAL_CATALOG` 指向 OJ Insight 的 `xcpc-catalog.json`。服务启动后在后台导入，随后每 30 秒检查文件是否更新。只有带有效榜单统计的题目才会入库，数据库按比赛和题号保存参赛队数、通过队数、档位和榜单来源；页面只查询本地结果。请在 OJ Insight 更新赛事榜单以补全数据。
